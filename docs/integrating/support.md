# Support

opengrowth is an open-source project of the [Open Health Technology Foundation](https://openhealthtechnology.org), supported by its community. There is no paid support service.

- **Questions, problems, and ideas:** open an [issue](https://github.com/ohtf/opengrowth/issues) on GitHub. Search the existing issues first: your question may already have an answer.
- **Anything that could change a calculated result:** open an issue labelled `hazard`, which is handled as a safety report ([SAFETY.md](https://github.com/ohtf/opengrowth/blob/main/SAFETY.md)).
- **Security vulnerabilities:** report them privately, never in a public issue ([Security](security.md#reporting-a-vulnerability)).
- **Contributing:** fixes and improvements are welcome, to the code and to these pages ([Contributing](../about/contributing.md)).
- **News:** join the OHTF [mailing list](https://openhealthhub.org/t/open-health-technology-foundation-cic-start-here-join-the-mailing-list/3094) on Open Health Hub.

For RCPCH's Digital Growth Charts service, which opengrowth is not part of, see RCPCH's own [documentation](https://growth.rcpch.ac.uk).
